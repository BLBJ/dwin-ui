
# DWIN UI

# 介绍

一款基于vue3的UI公共库组件，简洁友好，适合新手学习，快速上手。

另包含一个vitepress的开发文档工程，方便快速搭建和维护组件文档。

# 目录介绍

/docs   开发文档搭建
/packages   公共组件源码

# 运行命令

安装依赖

`npm install`

运行组件库测试

`npm run dev`

运行文档工程

`npm run docs:dev`

文档打包

`npm run docs:build`

文档部署

`npm run docs:deploy`

组件库更新后，需先打包再运行文档工程

`npm run build`
