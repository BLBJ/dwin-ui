# 主题配置

dwin-ui 支持自定义主题配置，开发者可根据需要修改基础色值。

## 默认色值

```css
 {
  --color-primary: #2b8ce5;
  --color-error: #f53f3f;
  --vt-c-header-height: 48px;
  /* 模块通用背景色 */
  --color-background: #232324;
  --tab-background: #161618;
  --color-background-content: #292a2c;

  /*操作框背景*/
  --color-background-input: #292a2c;
  --color-background-hover: rgba(255, 255, 255, 0.04);
  --color-background-active: rgba(255, 255, 255, 0.1);
  --color-disabled: rgba(255, 255, 255, 0.3);
  --dispatch-color-background: #39393a;
  --dispatch-hr-background: #39393a;
  --calendar-background: rgba(255, 255, 255, 0.04);
  --calendar-backo: rgba(43, 140, 229, 0.5);
  --calendar-backt: rgba(167, 174, 188, 0.6);
  --calendar-backr: rgba(255, 255, 255, 0.08);
  --color-background-schedule: rgba(255, 255, 255, 0.11);
  /* 文字 */
  --color-text: #c0c4cc;
  --color-text-disabled: #605b5b;
  --color-text-hover: #ffffff;
  --color-text-active: var(--color-primary);
  --color-text-selected: #ffffff;
  --color-text-btn: #ffffff;
  --color-title: #ffffff;
  --color-text-ploceholder: #757575;
  --dispatch-downUp-background: none;
  --dispatch-active-background: #4f4f4f;
  /*边框线*/

  --picker-next: #39393a;

  /*菜单*/

  --map-tab-back: rgba(255, 255, 255, 0.1);
  --box-shadow-color: #08080a;
}
```
